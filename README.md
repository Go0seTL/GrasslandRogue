# 草原枪手 · Grassland Gunner

浏览器端像素风肉鸽射击原型，玩法参考《元气骑士》。当前是**单机 + 双人房间码合作（测试版）**，可以直接在电脑或手机浏览器里玩。

## 启动

**电脑本地（推荐）**

双击 `run.bat`，会自动启动本地服务器并打开：

```
http://127.0.0.1:8123/
```

需要本机安装 Python 3。关闭黑窗口即停止服务。

**直接打开**

双击 `index.html` 也能跑，但部分浏览器会限制本地 `localStorage` 存档，建议用 `run.bat`。

**手机 / 公网**

把整个静态目录上传到 GitHub Pages、Netlify 或 Vercel 即可，不需要游戏服务器。游戏使用相对路径，部署在子路径下也能正常运行。

## 联机合作（双人）

- 主菜单 →「联机合作」。
- **房主**：点「创建房间」，把显示的 6 位数字房间码发给朋友；朋友加入后点「开始游戏」。
- **客人**：点「加入房间」，输入 6 位房间码，等待房主开始。
- 双方都可以在 Lobby 点「选择角色 / 戒指」，用自己已解锁的角色和已拥有的戒指出战；**开局后不能换角色/戒指**。
- 房主是主机，负责怪物、掉落和关卡；客人看到自己的视角和独立 HUD（生命、能量、武器、技能/开火/翻滚/切枪按钮），不再是房主画面。
- 客人有独立技能按钮（援护爆发）和切枪按钮；移动、瞄准、开火、翻滚都会同步给房主。
- 联机使用 PeerJS 公共信令 + WebRTC 状态同步，不需要自建游戏服务器；但双方都要能访问互联网。严格 NAT、公司/校园网可能连不上，后续可以自建 PeerServer + TURN 中继提高成功率。
- 队友倒地后不会立刻结束：另一名玩家走到身边**站着不动 4 秒**可以救援；两人同时倒地才结束，并给双方弹出结算界面。

## 操作

| 操作 | 电脑 | 手机 |
|---|---|---|
| 移动 | W A S D / 方向键 | 左半屏拖动（虚拟摇杆） |
| 瞄准 | 鼠标指向 | 右半屏拖动；不拖时自动瞄准最近敌人 |
| 射击 | 按住鼠标左键 | 右下角「射击」按钮（默认手动；暂停菜单可开自动射击） |
| 翻滚 | 空格 / Shift | 右下角「闪」按钮 |
| 技能 | E | 右下角技能按钮（在射击按钮左侧） |
| 切枪 | Q | 技能按钮左侧「切枪」按钮 |
| 暂停 | Esc / P | 右上角暂停按钮 |
| 静音 | M | 主菜单「音效」按钮 |

### 手机全屏 / iPhone

- 游戏会自适应刘海、底部横条和浏览器可视区域，HUD 不会再被浏览器 UI 压住。
- 安卓 / 电脑：主菜单点「全屏模式」进入全屏。
- **iPhone Safari 不支持网页直接全屏**：点 Safari 底部的「分享」→「添加到主屏幕」，从桌面图标打开「草原枪手」，就会以全屏 PWA 方式运行。

## 当前内容

### 角色

- **枪手**：免费初始角色；初始手枪；技能「自动索敌」——锁定最近 3 名敌人，角色冒火，**同时向 3 个目标开火**，用当前手持武器自动攻击 3 秒；拿枪就按该枪的弹道、伤害、射速和弹丸数量打，拿近战武器则自动挥砍，目标死亡会立即转火。
- **剑客**：需要 **800 金币**解锁；斗笠 + 蓝衣造型；初始武器同样是无限弹药手枪；技能「万剑归宗」——身边召唤 8 把剑停顿 1 秒，然后锁定附近的敌人刺出；命中造成伤害，目标死亡会转火到最近的敌人，剑飞出地图后消失。
- **科学怪人**：需要 **3000 金币**解锁；绿色皮肤、护目镜、白色实验服造型；技能「巨型化」——变成体型巨大的绿色巨人持续 **10 秒**，期间普通攻击改为近战铁拳（基础 95 伤害、范围大、能砍掉敌方子弹，攻速受角色升级影响），冷却 **30 秒**。巨人形态结束后自动恢复原样和当前武器。
- **法师**：需要 **1800 金币**解锁；紫色法师帽造型；技能「持续激光」——朝当前面向发射一束持续 **8 秒**的激光，移动鼠标/摇杆改变朝向后激光同步转向，持续伤害沿线敌人。
- **吉他手**：需要 **2200 金币**解锁；技能「音浪」——持续 **6 秒**在自身周围形成音浪，每 0.38 秒对范围内敌人造成伤害，期间移速大幅提升。
- **恶魔**：需要 **3200 金币**解锁；技能「恶魔契约」——开启时随机失去当前生命的 **30%–70%**（最少保留 1 点生命），持续 **5 秒**内攻击力提升、攻速翻倍、无限能量；不消耗能量。
- **吸血鬼**：需要 **2600 金币**解锁；技能「生命汲取」——持续 **5 秒**从周围最多 **5 个敌人**身上吸取生命，造成持续伤害并回复自身。
- **骑士**：需要 **1200 金币**解锁；技能「圣盾」——4 秒内免疫所有伤害，冷却 18 秒。
- **游侠**：需要 **2500 金币**解锁；技能「箭雨」——锁定最近 3 名敌人各射 4 箭，没有目标时环形齐射，冷却 14 秒。
- **刺客**：需要 **3500 金币**解锁；技能「影袭」——瞬移到最近敌人身后，对周围敌人造成高额伤害；**直接斩杀生命 ≤20% 的敌人，斩杀成功立刻重置技能冷却**。
- **炼金术士**：需要 **5000 金币**解锁；技能「毒瓶」——朝最近敌人投掷数个毒瓶，落地形成毒圈；毒圈内敌人持续中毒（绿色迷雾 + 头顶骷髅漩涡），友军站在毒圈里缓慢回血。冷却 16 秒。
- 所有可玩角色都需要金币解锁；角色等级与技能等级分开升级。角色升级只加生命/能量/武器伤害/攻速，**不再增加技能伤害**；技能伤害/持续时间要在选人界面点「技能升级」单独提升。骑士、科学怪人的技能升级加**持续时间**。
- 金币在死亡后保留，角色解锁永久生效。

### 关卡

- 从 `1-1` 开始，每轮 6 关，共 10 轮；**第 1–2 轮是草原，第 3–5 轮是山地，第 6 轮是墓地，第 7–9 轮是「龙巢」，第 10 轮是「天堂」**。普通模式在 **10-6 击败最终 Boss「天使」后通关**。
- 普通房分波刷史莱姆、哥布林弓手、蝙蝠；史莱姆有概率分裂成小史莱姆。
- **第二轮开始**新增两种怪：
  - **蘑菇射手**：移动缓慢，停顿蓄力后吐出 3 颗孢子。
  - **冲锋野猪**：先蓄力，再沿直线高速冲撞，撞墙后停下。
- **第三轮开始**新增**山羊精**：先在原地停顿蓄力，再朝锁定方向发射一道贯穿激光，看到红线要横向躲开。
- **第六轮开始**新增**亡灵**：平时隐身、移动很慢，靠近玩家才会现形；受到伤害后强制现形 3 秒，期间再次受伤会重置 3 秒；现形后会朝玩家**连射 3 发子弹**。
- **第七轮开始**新增**小飞龙**：绕圈飞行并吐火球；7-6 是 **飞龙宝宝** Boss（火球、龙息、俯冲，半血后更频繁）。
- **第十轮天堂**新增三种小怪：**天使侍从**（保持距离连射 3 发圣光弹）、**云端精灵**（快速绕圈接触）、**圣殿骑士**（高生命近战重击）；10-6 是最终 Boss **天使**，会释放环形圣光、追踪光弹并召唤侍从，半血后进入圣辉形态。
- **精英怪**：普通怪的强化版，体型更大、周围有金色粒子光环、头顶有「精英」标签；生命约 2 倍、伤害更高，金币和碎片掉落翻倍。轮次越高出现概率越高。
- 敌人生命和伤害随关卡、轮次持续增长；越往后越难。
- Boss 按轮次轮换：
  - 1-6：史莱姆王（跳跃砸地、环形弹幕、暴怒召唤）
  - 2-6：**野猪王**（狂暴冲撞会优先朝玩家方向、且不会撞出地图；石头雨落点有红圈预警）
  - 3-6：**精英史莱姆王 / 精英野猪王**（随机，生命 ×1.6、伤害 ×1.3）
  - 4-6：**蘑菇怪客**（短时间反射子弹、三轮会减速的环形弹幕）
  - 5-6：**精英蘑菇怪客 + 蝙蝠王**。蝙蝠王会遮蔽玩家视野 4 秒，也会瞬移到玩家身后发射一圈弹幕；精英蘑菇怪客的环形弹幕由 3 轮变 6 轮。
  - 6-6：**山羊王 + 随机的精英王**（精英史莱姆王 / 精英野猪王 / 精英蘑菇怪客三选一）。山羊王会停顿蓄力后扇形发射多道贯穿激光，半血后激光数量增加。
  - 7-6：**飞龙宝宝**（扇形火球、长条龙息、俯冲；半血后攻击频率提高）。
  - 8-6：随机精英 Boss 组合；9-6：飞龙宝宝强化版。
  - **10-6：最终 Boss「天使」**。击败后通关，不再进入下一轮。
  - **精英 Boss 技能翻倍**：精英史莱姆王召唤双倍史莱姆，精英野猪王石头雨数量翻倍，精英蘑菇怪客弹幕 3 轮变 6 轮。
- **恶魔传送门**：每轮 Boss 击败后有 30% 概率出现，整局最多一次。进入后到「恶魔之地」挑战 **撒旦**：**20 倍普通 Boss 血量**，第一阶段会投三叉戟、召唤 6–10 个恶魔卫兵、巨掌拍击和三叉戟突刺；打空第一阶段后以 1/3 血量进入第二阶段。二阶段硫磺火**不再锁头追踪**，按四种轨迹喷射：五角星、三行五列网格、朝敌人方向的弧形扇射、以撒旦为中心画两个圆。击败后必定获得 **撒旦之心**，走返回传送门回到原回合。
- Boss 血量整体提高约 50%，伤害降低约 20%；具体数值随轮次继续增长。
- 清空房间后出现传送门，走进去进入下一关；清房回血；进入传送门前会自动拾取地上所有金币、碎片、血包和能量包。

### 无尽挑战

- 主菜单 →「无尽挑战」→ 选角色 → 选戒指 → 开始。
- 地图约为普通地图面积的 **4 倍**（1920×1080 世界，镜头跟随角色）；没有最终波次，能打多久打多久。
- 每波怪物数量很多，生命、伤害和攻击频率随波次提高；精英怪概率一路提高。
- 从第 4 波开始有概率刷 Boss，越往后概率和数量越高：最多可能同时出现 **5 个 Boss**，并且会出现精英 Boss。
- 每清空一波自动回复生命，获得金币、武器碎片和戒指碎片奖励；随后进入三选一强化，选完立刻开始下一波。
- 无尽模式不写「继续游戏」检查点，死亡或退出后需要重新开始。

### 武器与碎片

- 所有角色每局**初始武器固定为无限弹药手枪**。
- 其他武器不能购买，只能靠**碎片合成**，需求已整体提高：
  - 品质：白色 → 绿色 → 蓝色 → 紫色 → 红色 → 金色 → 彩色
  - 碎片需求：绿色 20、蓝色 45、紫色 90–100、红色 160、金色 260、彩色 5
  - 小怪按品质权重掉碎片，品质越高越稀有，并且有保底
  - **彩色碎片只由对应 Boss 掉落**：史莱姆王 → 史莱姆王的法杖，野猪王 → 野猪王之斧，蘑菇怪客 → 蘑菇怪法球，山羊王 → 山羊之眼
- 主菜单「武器锻造」或游戏内右上角「武器」查看碎片进度、合成、装备；共 **22 把武器**（锻造分 3 页）。
- **蘑菇怪法球**：以角色为中心向四周射出一整圈 24 发密集球状子弹。
- 已实现武器：
  - 近战：**小刀**（白色，免费）、**武士刀**（紫色）、**野猪王之斧**（彩色，Boss 掉落）
  - 远程：手枪、霰弹枪、冲锋枪、猎枪、火焰喷射器、磁暴步枪、史莱姆王的法杖、**蘑菇怪法球**（彩色，环形弹幕）、**蓄力弓**、**狙击枪**、**回旋镖**、**弹弓**、**弩箭**（后四把都长按蓄力/特殊弹道）
  - 元素法杖：**火元素法杖**（红色，火球附加 2 秒灼烧）、**水元素法杖**（蓝色，穿透并回能）、**风元素法杖**（绿色，高射速风刃）、**山羊之眼**（彩色，长按发射金色贯穿激光）
  - 恶魔武器（彩色，奇旅商人兑换碎片）：**恶魔三叉戟**（轻点近战横扫，长按投掷）、**恶魔硫磺火**（长按喷射粗红色激光）
- 近战武器不会发射子弹，而是在面前挥出弧形斩击，可同时命中多个敌人，**还能砍掉范围内的敌方子弹**。
- 非手枪武器每次射击消耗能量；彩色/高品质武器有更强的彩色枪口、命中和弹道粒子效果。
- **火焰喷射器**：命中后附加 2 秒灼烧，持续掉血，目标身上有橙色火焰粒子与光晕；再次命中会刷新灼烧时间。
- **史莱姆王的法杖**：每第 3 次攻击额外以角色为中心发射一圈 12 发环形弹幕。
- **野猪王之斧**：长按攻击 0.65 秒召唤覆盖全图的石头雨（橙色落点预警，砸击附近敌人）；**按住不松手会持续召唤多波**，蓄力期间移动速度大幅降低；短按仍然是近战挥砍。
- **狙击枪 / 弹弓 / 弩箭**：长按蓄力，松开射出不同速度、伤害、穿透的弹道。
- **回旋镖**：长按蓄力掷出，飞出后自动返回，去程/回程都能伤害敌人。
- **恶魔三叉戟**：轻点近战高伤害横扫，长按掷出远程三叉戟。
- **恶魔硫磺火**：长按持续喷射粗大的红色激光，沿直线灼烧并点燃敌人。
- 碎片和已解锁武器永久保存；已解锁武器可以在后续局里免费装备。

### 戒指

- 击败小怪/精英/Boss 有概率掉落**戒指碎片**；戒指碎片在「戒指」界面合成。戒指和武器一样永久保存碎片和已合成戒指。
- 一局只能装备 **1 枚**戒指，效果只在本局生效；**阵亡后当前装备的戒指直接遗失**（已合成的其他戒指保留）。
- 戒指列表：
  - **不死戒指**：抵挡一次致命伤害。
  - **血红戒指**：每击杀一个单位，本局生命上限 +2（有上限）。
  - **蔚蓝戒指**：能量回复速度约 ×3。
  - **传送戒指**：进入传送门时随机传送到一个关卡，每局一次。
  - **秒杀戒指**：第一次攻击直接秒杀一个单位，每局一次。
  - **幻影戒指**：获得闪避伤害几率，基础 1%，移动越快几率越高。
  - **财富戒指**：每次攻击有 20% 几率掉落金币。
- 主菜单和游戏内右上角都有「戒指」入口。
- **选完角色后先进入戒指面板**，选择 1 枚已有戒指（也可以不戴），再点「开始冒险」进入游戏；无尽挑战和死亡后再战也走同一流程。**游戏开始后不能换戒指，游戏内没有戒指按钮**。无尽模式禁用传送戒指。

### 佣兵

- 普通房间有 **7%** 的低概率出现未收买的佣兵；靠近后出现「收买」按钮，花金币让他加入本局。每轮最多出现 2 次，且同一个佣兵存活时不会再刷第二个。
- 佣兵有独立血条，会被敌方子弹和接触伤害杀死；死亡后本局内还有机会在其他房间遇到新佣兵。
- 靠近已加入的佣兵会出现「给武器」按钮，把玩家当前武器交给佣兵使用（玩家自己仍保留该武器）；佣兵没有蓝条。
- 佣兵攻击约 4 秒后会休息 2–2.6 秒，休息期间名字旁显示「休息中」；离开房间会跟随玩家。佣兵攻击时会保持横向移动，不会站桩；给他枪后仍会交替使用原本的黑刃/手雷攻击。
- **暄暄**：不戴眼镜、瘦高、黑色长风衣，默认武器是范围很长的黑色大刀；收买价 120 金币。
- **亮宝**：戴眼镜、高壮、绿色外套，默认武器是手雷，落地范围爆炸并让敌人灼烧 2 秒；收买价 160 金币。
- 佣兵只在本局存在，不会跨新开的一局保留；继续游戏检查点会保留已收买的佣兵状态。

### 奇旅商人

- 普通房间除佣兵外，还有 **6%** 概率出现奇旅商人；靠近后出现「交易」按钮，每轮最多出现 2 次。
- 每次商人随机生成 **3 个交易项**：金币买普通武器碎片、撒旦之心换恶魔武器碎片、卖出溢出碎片换金币（没有可卖碎片时会替换成另一项购买）。
- 撒旦之心只能通过击败撒旦获得；恶魔三叉戟/恶魔硫磺火碎片也可以在背包/锻造里查看和合成。

### 金币、血包、图鉴、强化

- 击杀怪物掉落 1–3 金币，自动吸附拾取，永久保存；金币用于角色解锁和角色升级。
- 怪物有概率掉落**绿色十字血包**（回 18 血）和**蓝色能量包**（回 35 能量）。
- **能量系统**：HUD 有独立能量条，自动回复（14/秒）。技能消耗 40 能量（恶魔的「恶魔契约」改为献祭生命），翻滚消耗 20 能量，除手枪外的武器每次射击也消耗能量（近战、蓄力弓同样消耗）；能量不足时无法释放/射击。
- **手机射击**：默认关闭自动射击，右下角「射击」按钮按住手动开火；暂停菜单里的「手机自动射击」可手动开启。桌面端会隐藏射击按钮，仍然用鼠标左键射击。
- **切枪**：右下角技能按钮左侧的「切枪」（电脑按 Q）；能量大于 0 时切换回上一次使用的武器，能量为 0 时自动切回无限弹药手枪。
- **角色升级**：选人界面「角色升级」或游戏内右上角「升级」按钮可花金币给当前角色升级，**没有等级上限**；价格改为线性增长（100 → 160 → 220……，不再翻倍）。HUD 头像旁会显示当前 `Lv.X`。每级提升变小：
  - 生命上限 +5、能量上限 +5
  - 攻击力 / 技能伤害 +2%
  - 攻击速度 +1%（最高 +30%）
  - 角色等级按角色分别保存。
- 主菜单「怪物图鉴」或游戏内右上角「图鉴」查看所有怪物（含新怪、Boss、恶魔卫兵、撒旦、小飞龙和飞龙宝宝），共 3 页。
- 游戏内右上角「背包」只看**物品数量**：撒旦之心、已拥有的武器碎片、戒指碎片，按品质排列；不再展示武器图鉴/解锁状态。
- **背景音乐**：菜单开始交互后会播放 WebAudio 合成的 8-bit 循环 BGM，本次增加了主旋律层；音效/BGM 都可在主菜单静音。
- 主菜单「激活码」：输入有效激活码可领取奖励（具体激活码不公开；每个存档的奖励只能领取一次）。
- 未制作完成的角色解锁后会显示「已解锁 · 制作中」，仍不能出战。
- 海克斯式三选一强化：普通模式开局一次、每个 Boss 房通关后一次；无尽模式每波结束一次。目前共 **43 个强化**。双持大师的副手武器可以在游戏内「武器锻造」里点「副武器」自行选择。
  - 普通强化（节选）：大而有力、疾风步、火力全开、拾金者、铁壁、技能大师、吸血、专注、铁甲护体、再生、能量核心、幸运、磁铁、点金手、玻璃大炮、翻滚大师、穿甲弹、暴击、荆棘、远射、超载、堡垒、处刑、急救、拾荒者、快手
  - **史诗强化（出现概率较低）**：
    - 幽灵宝宝：召唤跟随作战的幽灵宝宝，远程吐白色小球；主人濒死时传送到安全位置并免疫 3 秒
    - 死亡爆破：击杀敌人 30% 概率引发范围爆炸
    - 双生弹幕：每次射击 35% 概率额外发射一颗子弹
    - 双持大师：同时持有两把不同的已拥有武器（自动装备品质最高的另一把），两把武器同时开火
    - 无限财宝：每活过一轮存 200 金币，可随时取财；死亡则全部失去
    - 不掉一根毛：本轮全程无伤通关 Boss，获得紫色以上武器碎片和戒指碎片大礼
  - 强化界面可以花 **30 金币刷新**三个选项；没有跳过按钮。
- **自动存档与继续游戏**：金币、角色解锁、武器碎片、戒指碎片、已解锁武器/戒指、角色等级、激活码状态都存 `localStorage`。金币约每 2 秒落盘，清房、死亡、购买/升级和切后台/关页面时也会立即保存。
  - 每次进入新房间、选择强化、装备武器、角色升级、清房时都会记录一个**房间检查点**。
  - 主菜单会出现「继续游戏 · 4-3」这样的按钮，回到退出时所在的回合/关卡；**当前房间的怪物会重新刷新**，生命和能量回满，角色、武器、双持、强化和幽灵宝宝都会保留。
  - 死亡后检查点清空，不能继续已结束的一局；当前装备的戒指会按规则遗失。点「开始新冒险」会从 1-1 开新局。
  - 手机用同一个网址再打开会恢复之前的进度；清除浏览器网站数据/换网址会丢存档，私密浏览模式也不保存。

## 技术栈

- **Phaser 3.90**，纯浏览器运行，无构建步骤。
- 所有像素贴图（角色、史莱姆、Boss、草地、树篱、金币、武器、UI 图标）在启动时用 Canvas **程序化生成**，不依赖外部图片。
- 音效与 8-bit 背景音乐用 **WebAudio 现场合成**，不依赖音频文件。
- 触屏用 Phaser 多点触控实现双摇杆 + 技能/翻滚按钮。
- 固定 960×540 逻辑分辨率，`Phaser.Scale.FIT` 自适应电脑和手机横屏。
- 对象使用分组管理，子弹/粒子/金币/碎片及时销毁。

## 调平衡

大部分数值集中在 `src/config.js`：

- `BALANCE`：玩家血量、移速、射速、子弹伤害、翻滚冷却、清房回血
- `SKILL`：枪手技能持续时间、冷却、锁定数量（枪手自动射击的伤害/射速由当前武器决定）
- `GIANT`：科学怪人巨人形态的持续时间、冷却、拳头伤害/范围/攻速、体型
- `GUITAR`：吉他手音浪的持续时间、冷却、半径、伤害间隔
- `DEMON`：恶魔契约的持续时间、冷却、伤害倍率和攻速倍率
- `VAMPIRE`：吸血技能持续时间、冷却、最多目标数、伤害和回复比例
- `MAGE_LASER`：法师激光的持续时间、冷却、长度、宽度和伤害间隔
- `FLAMER_BURN`：火焰喷射器灼烧时长与每秒伤害
- `BOAR_AXE`：野猪王之斧长按蓄力时间、石头雨数量、冷却和减速比例
- `WEAPONS`：武器品质、碎片需求、伤害、射速、弹丸、穿透
- `FRAGMENT_RULES`：碎片掉率、品质权重、保底击杀数、Boss 彩色碎片
- `UPGRADES`：海克斯强化列表
- `ENEMY_DEFS` / `ENEMY_LORE`：敌人数值与图鉴介绍

## 部署到 GitHub Pages

游戏是纯静态页面，不需要后端；手机用移动网络也能打开。
