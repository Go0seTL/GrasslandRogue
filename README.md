# 草原枪手 · Grassland Gunner

浏览器端像素风肉鸽射击原型，玩法参考《元气骑士》。当前是**单机试玩版**，可以直接在电脑或手机浏览器里玩。

## 启动

**电脑本地（推荐）**

双击 `run.bat`，会自动启动本地服务器并打开：

```
http://127.0.0.1:8123/
```

需要本机安装 Python 3。关闭黑窗口即停止服务。

**直接打开**

双击 `index.html` 也能跑，但部分浏览器会限制本地 `localStorage` 存档，建议用 `run.bat`。

**手机 / 公网**

把整个静态目录上传到 GitHub Pages、Netlify 或 Vercel 即可，不需要游戏服务器。游戏使用相对路径，部署在子路径下也能正常运行。

## 操作

| 操作 | 电脑 | 手机 |
|---|---|---|
| 移动 | W A S D / 方向键 | 左半屏拖动（虚拟摇杆） |
| 瞄准 | 鼠标指向 | 右半屏拖动；不拖时自动瞄准最近敌人 |
| 射击 | 按住鼠标左键 | 触屏模式下自动开火 |
| 翻滚 | 空格 / Shift | 右下角「闪」按钮 |
| 技能 | E | 右下角技能按钮 |
| 暂停 | Esc / P | 右上角暂停按钮 |
| 静音 | M | 主菜单「音效」按钮 |

### 手机全屏 / iPhone

- 游戏会自适应刘海、底部横条和浏览器可视区域，HUD 不会再被浏览器 UI 压住。
- 安卓 / 电脑：主菜单点「全屏模式」进入全屏。
- **iPhone Safari 不支持网页直接全屏**：点 Safari 底部的「分享」→「添加到主屏幕」，从桌面图标打开「草原枪手」，就会以全屏 PWA 方式运行。

## 当前内容

### 角色

- **枪手**：免费初始角色；初始手枪；技能「自动索敌」——锁定最近 3 名敌人，角色冒火，**用当前手持武器**自动射击 3 秒；拿枪就按该枪的弹道、伤害、射速和弹丸数量打，拿近战武器则自动挥砍，目标死亡会立即转火到最近敌人。
- **剑客**：需要 **800 金币**解锁；斗笠 + 蓝衣造型；初始武器同样是无限弹药手枪；技能「万剑归宗」——身边召唤 8 把剑停顿 1 秒，然后锁定附近的敌人刺出；命中造成伤害，目标死亡会转火到最近的敌人，剑飞出地图后消失。
- 骑士（1200）、法师（1800）、游侠（2500）、刺客（3500）、炼金术士（5000）仍为未开放状态，价格已预留。
- 金币在死亡后保留，角色解锁永久生效。

### 关卡

- 从 `1-1` 开始，每轮 6 关；**第 1–2 轮是草原，第 3 轮开始切换到「山地」**（松林、石头地和山岩），Boss 房也一起换。
- 普通房分波刷史莱姆、哥布林弓手、蝙蝠；史莱姆有概率分裂成小史莱姆。
- **第二轮开始**新增两种怪：
  - **蘑菇射手**：移动缓慢，停顿蓄力后吐出 3 颗孢子。
  - **冲锋野猪**：先蓄力，再沿直线高速冲撞，撞墙后停下。
- **第三轮开始**新增**山羊精**：快速蓄力后头槌冲锋。
- **精英怪**：普通怪的强化版，体型更大、周围有金色粒子光环、头顶有「精英」标签；生命约 2 倍、伤害更高，金币和碎片掉落翻倍。轮次越高出现概率越高。
- 敌人生命和伤害随关卡、轮次持续增长；越往后越难。
- Boss 按轮次轮换：
  - 1-6：史莱姆王（跳跃砸地、环形弹幕、暴怒召唤）
  - 2-6：**野猪王**（狂暴冲撞会优先朝玩家方向、且不会撞出地图；石头雨落点有红圈预警）
  - 3-6：**精英史莱姆王 / 精英野猪王**（随机，生命 ×1.6、伤害 ×1.3）
  - 4-6：**蘑菇怪客**（短时间反射子弹、三轮会减速的环形弹幕）
  - 第 5 轮起循环，属性继续随轮次增长。
- Boss 生命 560 起，随轮次明显增强。
- 清空房间后出现传送门，走进去进入下一关；清房回血。

### 武器与碎片

- 所有角色每局**初始武器固定为无限弹药手枪**。
- 其他武器不能购买，只能靠**碎片合成**，需求已整体提高：
  - 品质：白色 → 绿色 → 蓝色 → 紫色 → 红色 → 金色 → 彩色
  - 碎片需求：绿色 20、蓝色 45、紫色 90–100、红色 160、金色 260、彩色 5
  - 小怪按品质权重掉碎片，品质越高越稀有，并且有保底
  - **彩色碎片只由对应 Boss 掉落**：史莱姆王 → 史莱姆王的法杖，野猪王 → 野猪王之斧，蘑菇怪客 → 蘑菇怪法球
- 主菜单「武器锻造」或游戏内右上角「武器」查看碎片进度、合成、装备；共 **12 把武器**。
- 已实现武器：
  - 近战：**小刀**（白色，免费）、**武士刀**（紫色）、**野猪王之斧**（彩色，Boss 掉落）
  - 远程：手枪、霰弹枪、冲锋枪、猎枪、火焰喷射器、磁暴步枪、史莱姆王的法杖、**蘑菇怪法球**（彩色，环形弹幕）、**蓄力弓**（紫色，长按蓄力松手射击）
- 近战武器不会发射子弹，而是在面前挥出弧形斩击，可同时命中多个敌人，**还能砍掉范围内的敌方子弹**。
- 非手枪武器每次射击消耗能量；彩色/高品质武器有更强的彩色枪口、命中和弹道粒子效果。
- 碎片和已解锁武器永久保存；已解锁武器可以在后续局里免费装备。

### 金币、血包、图鉴、强化

- 击杀怪物掉落 1–3 金币，自动吸附拾取，永久保存；金币用于角色解锁和角色升级。
- 怪物有概率掉落**绿色十字血包**（回 18 血）和**蓝色能量包**（回 35 能量）。
- **能量系统**：HUD 有独立能量条，自动回复（14/秒）。技能消耗 40 能量，翻滚消耗 20 能量，除手枪外的武器每次射击也消耗能量（近战、蓄力弓同样消耗）；能量不足时无法释放/射击。
- **角色升级**：选人界面「角色升级」或游戏内右上角「升级」按钮可花金币给当前角色升级，**没有等级上限**，每次升级价格翻倍（200 → 400 → 800……）。游戏内升级会立即提升当前这一局的生命/能量上限和攻击。每级提升：
  - 生命上限 +10、能量上限 +10
  - 攻击力 / 技能伤害 +4%
  - 攻击速度 +2%（最高 +55%）
  - 角色等级按角色分别保存。
- 主菜单「怪物图鉴」或游戏内右上角「图鉴」查看所有怪物（含新怪、Boss 和精英怪），共 2 页。
- 主菜单「激活码」：输入有效激活码可领取奖励（具体激活码不公开；每个存档的奖励只能领取一次）。
- 未制作完成的角色解锁后会显示「已解锁 · 制作中」，仍不能出战。
- 海克斯式三选一强化：开局一次，每个 Boss 房通关后一次。
  - 普通强化：大而有力、疾风步、火力全开、拾金者、铁壁、技能大师、吸血、专注
  - **史诗强化（出现概率较低）**：
    - 幽灵宝宝：召唤跟随作战的幽灵宝宝，远程吐白色小球；主人濒死时传送到安全位置并免疫 3 秒
    - 死亡爆破：击杀敌人 30% 概率引发范围爆炸
    - 双生弹幕：每次射击 35% 概率额外发射一颗子弹
    - 双持大师：同时持有两把不同的已拥有武器（自动装备品质最高的另一把），两把武器同时开火
  - 强化界面可以花 **30 金币刷新**三个选项；没有跳过按钮。
- **自动存档与继续游戏**：金币、角色解锁、碎片、已解锁武器、角色等级、激活码状态都存 `localStorage`。金币约每 2 秒落盘，清房、死亡、购买/升级和切后台/关页面时也会立即保存。
  - 每次进入新房间、选择强化、装备武器、角色升级、清房时都会记录一个**房间检查点**。
  - 主菜单会出现「继续游戏 · 4-3」这样的按钮，回到退出时所在的回合/关卡；**当前房间的怪物会重新刷新**，生命和能量回满，角色、武器、双持、强化和幽灵宝宝都会保留。
  - 死亡后检查点清空，不能继续已结束的一局；点「开始新冒险」会从 1-1 开新局。
  - 手机用同一个网址再打开会恢复之前的进度；清除浏览器网站数据/换网址会丢存档，私密浏览模式也不保存。

## 技术栈

- **Phaser 3.90**，纯浏览器运行，无构建步骤。
- 所有像素贴图（角色、史莱姆、Boss、草地、树篱、金币、武器、UI 图标）在启动时用 Canvas **程序化生成**，不依赖外部图片。
- 音效与 8-bit 背景音乐用 **WebAudio 现场合成**，不依赖音频文件。
- 触屏用 Phaser 多点触控实现双摇杆 + 技能/翻滚按钮。
- 固定 960×540 逻辑分辨率，`Phaser.Scale.FIT` 自适应电脑和手机横屏。
- 对象使用分组管理，子弹/粒子/金币/碎片及时销毁。

## 调平衡

大部分数值集中在 `src/config.js`：

- `BALANCE`：玩家血量、移速、射速、子弹伤害、翻滚冷却、清房回血
- `SKILL`：枪手技能持续时间、冷却、锁定数量（枪手自动射击的伤害/射速由当前武器决定）
- `WEAPONS`：武器品质、碎片需求、伤害、射速、弹丸、穿透
- `FRAGMENT_RULES`：碎片掉率、品质权重、保底击杀数、Boss 彩色碎片
- `UPGRADES`：海克斯强化列表
- `ENEMY_DEFS` / `ENEMY_LORE`：敌人数值与图鉴介绍

## 部署到 GitHub Pages

1. 新建一个公开仓库，例如 `GrasslandRogue`。
2. 上传 `index.html`、`lib/`、`src/`，以及一个空的 `.nojekyll` 文件。
3. Settings → Pages → Source 选择 `main` 分支、`/ (root)`，保存。
4. 等 1–2 分钟，打开 `https://<你的用户名>.github.io/GrasslandRogue/`。

游戏是纯静态页面，不需要后端；手机用移动网络也能打开。
